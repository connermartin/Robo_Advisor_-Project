## Quick start
```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # optional: add free Finnhub / FRED keys
streamlit run app.py
python -m pytest                 # run tests
```
